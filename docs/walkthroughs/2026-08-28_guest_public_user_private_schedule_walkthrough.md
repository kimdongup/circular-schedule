# 🌐 게스트 공개 시간표 및 🔒 로그인 회원 비공개 시간표 분리 저장 완료

게스트 모드에서 작성된 시간표는 **모든 사용자가 볼 수 있는 공개(Public) 라이브러리**에 저장되고, 로그인한 회원이 작성한 시간표는 **작성자 본인만 열람/수정할 수 있는 비공개(Private) 시간표**로 완벽하게 격리 저장되도록 구현을 완료하였습니다.

---

## 🛠️ 구현 내용 요약

### 1. 🔒 권한별 시간표 저장 분기 로직
- **게스트 모드 (비로그인)**:
  - `user_id = null`, `is_public = true`
  - 작성된 시간표는 대시보드에 **`🌐 공개 (Public)`** 뱃지와 함께 저장되며 모든 사용자가 열람할 수 있습니다.
- **로그인 회원 모드**:
  - `user_id = currentUser.id`, `is_public = false`
  - 작성된 시간표는 대시보드에 **`🔒 나만 보기 (Private)`** 뱃지와 함께 저장되며, 작성자 본인 계정으로 로그인했을 때만 표시됩니다.

### 2. 🗂️ 대시보드 실시간 RLS 연동 및 필터링
- Supabase Row Level Security(RLS) 정책을 통해 로그인 여부에 따라 자동으로 인가된 시간표만 쿼리합니다.
- 필터 칩 바:
  - 로그인 시 **`[🔒 내 비공개 시간표 (Private)]`** 필터 칩이 활성화되어 나만의 시간표만 모아볼 수 있습니다.
  - **`[🌐 공개 시간표 (Public)]`** 칩으로 공용 시간표 라이브러리를 탐색할 수 있습니다.

### 3. 🔄 로그인/로그아웃 시 자동 재동기화
- 로그인 성공 시 본인의 비공개 시간표를 즉시 불러오며, 로그아웃 시 비공개 시간표는 목록에서 즉시 숨겨집니다.
