# Google Workspace Migrate 스타일 시간표 관리 대시보드 UI/UX 개편 계획

첨부해 주신 **Google Workspace Migrate 대시보드 화면(카드 그리드, + New 버튼, 필터 탭, 상태 메트릭 뱃지, 진행률 프로그레스 바, 세부 액션)** 디자인을 벤치마킹하여, 기존의 단순 드롭다운 방식에서 **직관적이고 모던한 카드형 시간표 관리 허브(Dashboard Hub)**로 전면 개편합니다.

---

## 📸 벤치마킹 및 디자인 핵심 요소

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  🗓️ 원형 시간표 관리 시스템 (Circular Schedule Hub)                  [사용자 이메일] [🔔 푸시] │
├────────────────────────────────────────────────────────────────────────────────────────┤
│  [+ New 새 시간표]    내 시간표 보관함 > 등록된 시간표 목록         [총 시간표: 4개] [활동: 24개] │
│  [전체 State] [주간 시간표] [일일 시간표] [이름순 Name] [최근 수정순] [완료/보관됨]                │
├───────────────────────────────────┬────────────────────────────────────────────────────┤
│ 📋 사이드바 내비게이션              │ 🗂️ 시간표 카드 그리드 (2-Column Grid)               │
│ - 📊 시간표 대시보드 (Dashboard)   │ ┌──────────────────────────┐ ┌───────────────────┐│
│ - 🎨 시간표 편집기 (Editor/SVG)    │ │ 📌 나의 하루 시간표        ⋮│ │ 📌 주간 공부 계획   ⋮││

│ - ⚙️ 서버 관리자 (Admin)          │ │ [▶️ 열기] ⏱️ 14h 분량   │ │ [▶️ 열기] ⏱️ 8h 분량 ││
│                                   │ │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░ 85% 채움│ │ ▓▓▓▓▓▓░░░░░░ 50%   ││

│                                   │ └──────────────────────────┘ └───────────────────┘│
└───────────────────────────────────┴────────────────────────────────────────────────────┘
```

## User Review Required

> [!IMPORTANT]
> **대시보드와 원형 편집기(SVG) 간의 유기적 화면 전환**:
> - 대시보드에서 `+ New (새 시간표)` 또는 각 카드의 `[▶️ 시간표 열기/편집]` 버튼을 누르면 즉시 해당 시간표가 원형 SVG 편집기에 로드되고 편집 모드로 전환됩니다.
> - 상단 내비게이션 탭(`📊 대시보드` ↔ `🎨 원형 편집기`)을 통해 언제든 자유롭게 이동할 수 있습니다.

  - 경로 탐색 브레드크럼 (`내 시간표 보관함 > 등록된 시간표 목록`).
  - 필터 칩/탭 (`전체`, `주간`, `일일`, `최근 수정순`, `활동 많은 순`).

  - 2열 반응형 카드 그리드 레이아웃.
  - 각 카드별:
    1. **헤더**: 시간표 제목, 요약 뱃지, 도구 메뉴 (`...` 복제/공유/삭제).
    2. **컨텐츠**: 대형 `▶️ 열기/편집` 액션 버튼, 시간 범위(9시~21시), 최근 수정 일시.
    3. **타임라인 프로그레스 바**: 하루 12시간 중 활동이 채워진 비율을 시각화한 프로그레스 바.
    4. **통계 뱃지**: `🟢 완료`, `🟡 예정/진행 중`, `🔵 주말 일정`, `🟣 푸시 알림`.

### 3. 클라이언트 로직 (`public/app.js`)

#### [MODIFY] [app.js](file:///Users/mac/Antigravity/circular-schedule/public/app.js)
- **다중 시간표 관리 모델 (Multi-Schedule Management Model)**:
  - 게스트 모드(로컬 스토리지) 및 Supabase 클라우드 모드 모두에서 복수 시간표를 완벽 관리.
  - 각 시간표 객체 메타데이터: `{ id, title, items, updatedAt, createdAt, timeRange, totalHours, activeCount, isFavorite }`.
- **대시보드 렌더러 (`renderDashboard()`)**:
  - 시간표 목록을 첨부 이미지 스타일의 카드로 동적 렌더링.
  - 각 시간표의 활동 데이터를 분석하여 총 등록 시간(시간/분), 시간표 채움률(%), 카테고리별 일정 카운트를 자동 계산하여 뱃지와 프로그레스 바로 표시.
- **카드 인터랙션 액션**:
  - `▶️ 열기/편집`: 원형 편집기 화면으로 즉시 전환하고 해당 시간표 렌더링.
  - `📋 복제하기`: 기존 시간표를 복사하여 새 시간표 생성.
  - `🗑️ 삭제하기`: 확인 팝업 후 시간표 삭제.
  - `🔗 공유하기`: 공유 링크 자동 생성 및 클립보드 복사.
  - `+ New`: 빈 시간표 생성 후 편집기 진입.
- **필터링 및 정렬 기능**:
  - `이름순`, `최근 수정순`, `활동 많은 순` 필터 탭 클릭 시 즉시 실시간 정렬.

## Verification Plan

### 브라우저 및 화면 검증
1. **대시보드 렌더링 확인**:
   - `http://localhost:3000/` 접속 후 Google Workspace 스타일 상단 바, `+ New` 버튼, 필터 탭, 2열 카드 그리드가 스크린샷과 동일한 구조로 깔끔하게 렌더링되는지 확인.
2. **시간표 카드 세부 요소 확인**:
   - 시간표 제목, 시간 범위, `▶️ 열기` 버튼, 타임라인 프로그레스 바, 하단 메트릭 뱃지(`🟢 완료`, `🟡 예정`, `🔵 주말`, `🟣 푸시`)가 정확한 수치로 표시되는지 확인.
3. **인터랙션 동작 테스트**:
   - `+ New` 버튼 클릭 -> 새 시간표 생성 및 편집기 전환.
   - 카드 내 `▶️ 열기` 클릭 -> 해당 시간표 SVG 캔버스 로드.
   - 카드 도구 메뉴(`복제`, `삭제`, `공유`) 정상 동작 확인.
   - 필터 칩 클릭 시 시간표 카드 실시간 필터링/정렬 확인.
